# Budget & Investing Tracker

Private-by-default finance tracker built as a lightweight web app. Track income,
expenses, savings goals, and investment contributions in one clean dashboard.

## Quick Start

1. Start the backend server: `npm run dev`
2. Open `http://localhost:3001` in your browser.
3. Add entries for income, expenses, goals, and investments.
4. Use the dashboard filters to switch between months/years.
5. Export your data when you want to share or back it up.

## Data

- All entries are stored locally in your browser via `localStorage`.
- Use the Export button for a JSON backup.
